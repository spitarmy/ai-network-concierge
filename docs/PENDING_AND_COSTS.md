# 未決事項・費用設計メモ（正本の補助）

## 現時点で確定している費用方針

- 自分用の利用量: BNI 1to1 月30回以上、平均60分。設計上は月30〜60時間を耐える想定。
- 自分用運用原価: 月3,000円以下を**理想**、月約4,980円を予算の目安。固定上限や約束された実現可能費ではない。
- 将来のBNIメンバー向け主力価格: 月4,980円前後を希望。ただし正式な売価と録音時間枠は**まだ決定していない**。
- SaaS化時は録音回数より、追加費用が発生する議事録ボット時間・高コストAI処理の利用枠でプラン分けを検討。
- 初期版は料金プランや決済を完成させず、テナント単位の利用実績/原価台帳とプラン拡張のスキーマを持つ。
- API費用の正確な予測には、ホスト別の録音実績、既存文字起こしの活用率、ボット利用時間、文字起こし単価、長文解析単価、Web調査の回数、保存/通信費用が必要。現在の価格を無期限に固定しない。

## 技術検証・運用開始前に必要な確認

1. 本人のZoomプラン、クラウド録画/自動文字起こし設定、開発者OAuthの可能範囲。
2. Google Meetの利用アカウント・主催者権限・Google Workspaceプラン、録画/文字起こし成果物の入手可否。
3. 外部ホスト会議向け議事録ボットの提供事業者・利用規約・参加時の同意/表示方法・従量課金。
4. 相手に見せる録音・AI分析の同意文言、会議ごとの証跡方式、削除/保存期間の法務レビュー。
5. Gmail/Contactsの接続同意、利用対象範囲、Google OAuthアプリ審査の要否。
6. 全国BNIリージョン/チャプターの公開データの取得可能範囲、情報利用条件、修正ルート。全国完全網羅は未保証。
7. 自分で使うドメイン、公開時期、実ユーザー招待、正式名称・ロゴ。
8. 収録デバイスとの将来連携先、モバイルネイティブ化時期。
9. 90日録音保持を初期値にしたが、法務/利用者ニーズを確認し変更可能にする。

## 費用式（設計用。金額は運用時に最新料金で更新）

```text
月間変動費 = 有料議事録ボット時間×1時間単価
          + 外部文字起こし時間×1時間単価
          + AI文字処理（入力/出力トークン）
          + OCR画像処理（枚数）
          + 公開Web検索/調査（検索/トークン）
          + 保存（容量×保存期間）・転送
          + 決済手数料（将来）
月間固定費 = 認証/DB/サーバー/ジョブワーカー/ドメイン/監視など
販売粗利（概算） = 税抜売上 - 直接変動費 - 直接配賦インフラ/決済費
```

販売価格4,980円税込の場合、税抜売上は `4,980 / 1.1 ≒ 4,527円`（消費税10%の簡略例）。この売上と自分用月4,980円予算を混同しない。将来の広告、サポート、法務、開発維持費なども別途かかる。
