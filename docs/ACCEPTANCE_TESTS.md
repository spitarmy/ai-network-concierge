## テストデータの作り方（個人情報の持込み禁止）

- 山田太郎: 京都Aチャプター→京都Bチャプターへ移籍。事業は不動産仲介→買取再販。会社を2社経営。
- 佐藤花子: 相続専門司法書士、大阪対応、山田とは本人発言で知人。
- 田中一郎（別会社が2人）: 同姓同名で自動統合の誤判定をテスト。
- 中村社長: 会話に名前だけ登場する仮登録人物。フルネーム不明。
- 会議1: 山田と自分の60分1to1（同意あり）。
- 会議2: 山田/佐藤/田中の複数人会話（誰が「新店舗」と言ったか不明）。
- 会議3: 1人が同意しない会議（録音は一切しない）。
- 名刺例: ぼやけた漢字、片面情報の欠損、複数枚同時撮影、存在しない会社URL。
