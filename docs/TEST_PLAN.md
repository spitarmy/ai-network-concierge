## 1. テスト戦略と自動化構成

| レイヤー | フレームワーク | 主な検証内容 |
|---|---|---|
| **Unit / Logic** | Vitest (Front), pytest (Back) | 正規表現パーサー、名刺OCRバリデーション、事実矛盾検知、紹介スコアリング |
| **Database & RLS** | pgTAP / Supabase RLS tests | テナント完全分離（Tenant AからTenant Bのデータが見えないこと）、カスケード削除 |
| **API Integration** | pytest + httpx | エンドポイント検証、同意ステートマシン、冪等性キー、エラーハンドリング |
| **E2E / Browser** | Playwright | PC幅/iPhone幅表示、ライト/ダーク切替、予定登録フロー、カルテ編集Undo |

## 2. 受け入れテストIDのフェーズ割当マトリクス

| テストカテゴリ | テストID | 実装・検証フェーズ | 必須合格基準 |
|---|---|---|---|
| **UI・PWA体験** | `UX-01` 〜 `UX-10` | **P1** | PC/iPhone幅レスポンシブ、ライト/ダーク切替、シンプル/ダッシュボード切替、読み込み/空/エラー状態 |
| **人物・会社・履歴** | `PERSON-01` 〜 `PERSON-07` | **P1** | 複数事業・役職の独立性、チャプター移籍履歴、手動修正の不可逆性、誤名寄せ防止 |
| **事実・出典・仮カルテ** | `PERSON-08` 〜 `PERSON-12` | **P3** | 仮カルテ分離、facts出典・時点保持、公開範囲（私的情報の非公開性担保） |
| **名刺・インポート** | `CARD-01` 〜 `CARD-08` | **P2** | 原画対照OCR、勝手なWeb情報混入の遮断、曖昧漢字の確認待ち、CSVインポート |
| **予定・会議解析** | `MEET-01` 〜 `MEET-06` | **P2** | URL/文章からの予定抽出、固定URLの重複防止、会議種別選択 |
| **同意・収録** | `MEET-07` 〜 `MEET-10` | **P3** | 同意なし録音の遮断、1人拒否時の停止、同意の流用禁止、撤回時の即時破棄 |
| **外部会議連携** | `MEET-11` 〜 `MEET-17` | **P5** | Zoom自ホスト/相手ホスト区別、Meet制約、TimeTree手動扱い、個人LINE自動取得除外 |
| **AI会話解析・名寄せ** | `AI-01` 〜 `AI-06` | **P3** | 根拠セグメント付き要約、話者未特定情報の保留、プロンプトインジェクション耐性 |
| **AIチャット・音声** | `AI-07` 〜 `AI-11` | **P4** | 自然言語検索、でっちあげ防止（「不明」の誠実な回答）、音声フォールバック |
| **相関図** | `GRAPH-01` 〜 `GRAPH-04` | **P4** | 実関係 vs AI推薦の2モード切替、地域/チャプター絞込、大規模クラスタリング |
| **紹介・通知** | `INTRO-01` 〜 `INTRO-04` | **P4** | 説明可能な根拠、非公開情報の紹介除外、双方承諾下書き、未確認成果の自動確定禁止 |
| **セキュリティ・削除** | `SECURITY-01` 〜 `SECURITY-08` | **P1, P3, P6** | RLSテナント完全分離、90日自動破棄、本人の完全削除請求（U09）、Webhook署名検証 |
| **原価・予算** | `COST-01` 〜 `COST-05` | **P3, P6** | 利用量リアルタイム記録、80%警告、100%節約モード（高負荷ジョブ停止） |
